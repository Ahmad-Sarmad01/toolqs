## Quick Conversion Examples  
- **PNG → JPG**: Smaller file size, best for photos.  
- **JPG → PNG**: Retain transparency.  
- **WebP → PNG/JPG**: Needed for older browsers.  

---

## Compression vs Conversion  
- **Compression** = Reduce file size (same format).  
- **Conversion** = Change file format (e.g., PNG → JPG).  

Best practice? **Compress first, then convert if needed.**
